# week4-data-exploration-ml
DMACC Course work
Payton Cox and Machine Learning AAI 201 M4 Assignment | Data Exploration and Feature Engineering

This project explores the Adult Income dataset using Python, Pandas, Matplotlib, and Scikit-Learn. The goal is to perform data exploration, create visualizations, engineer new features, and build a machine learning model capable of predicting whether an individual's income exceeds $50,000 per year.

Dataset: Adult Income Dataset

The dataset contains demographic and employment information including:
- Age
- Education
- Occupation
- Marital Status
- Hours Worked Per Week
- Native Country
- Income Category

Several visualizations were created to better understand the data through six figures:
1. Income Distribution
2. Age Distribution
3. Hours Worked Per Week
4. Education Levels
5. Age vs. Hours Worked Scatter Plot
6. Feature Importance Visualization

These visualizations help identify trends, patterns, and relationships within the dataset.
